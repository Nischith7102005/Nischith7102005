# Portfolio

Personal portfolio site for Nischith R — business operations, supply chain, and technology management.

Built with Next.js (App Router), React, and Tailwind CSS. Static export, no server required.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is output to `/out` and can be hosted on any static host (Vercel, Cloudflare Pages, Netlify, GitHub Pages).
